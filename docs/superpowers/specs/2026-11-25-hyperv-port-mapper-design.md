# Hyper-V 端口映射客户端设计

## 目标与范围
用户需要一个 Windows 中文桌面工具，代替手工执行 netsh interface portproxy 命令。首版支持 IPv4 TCP 规则的查看、搜索、新增、编辑、删除；可选防火墙放行；检测虚拟机目标端口。映射保存在 Windows 系统中，关闭客户端后仍然有效。

## 技术选择
采用 C#、.NET 8 和 WinForms，无第三方运行时库。发布 Windows x64 自包含单文件 EXE。启动无需管理员权限，修改前提示通过 UAC 以管理员身份重启。只读模式也能查看规则和检测连接。

核心类库承载地址端口校验、冲突判断、命令参数和失败恢复。Windows 程序承载注册表读取、netsh 子进程、权限及界面。控制台检查程序引用核心类库，使用内存执行器验证系统变更的计划与恢复。

## 用户界面
主窗口使用浅色背景、深色标题、蓝色主按钮和明确的状态文字。上部显示权限和 IP Helper 状态；中部提供搜索、新增、刷新与规则表格；底部提供编辑、检测目标和删除。没有规则时显示空状态说明，读取失败时显示错误且禁用写入，不能显示为正常空列表。

新增与编辑对话框包含宿主机监听地址和端口、虚拟机地址和端口、可选的防火墙入站规则。明确显示 0.0.0.0 监听所有网卡，防火墙放行适用于所有网络，默认不选择。字段有标签和就地错误，支持 Enter 保存和 Esc 取消。保存时防止重复提交，操作失败后保留输入。

## 系统操作
- 从 HKLM 的 PortProxy/v4tov4/tcp 路径读取规则；不解析受系统语言影响的命令表头。
- 系统命令限定为 System32/netsh.exe；参数使用 ArgumentList，严格校验 IPv4 和端口。
- 每次变更前重新读取系统规则，检测规则已被其他程序修改或删除、重复监听和通配地址冲突。
- 检查当前 TCP 监听端口，排除原有规则本身；拒绝明显的占用和转发自环。
- 防火墙规则使用 HyperVPortMapper 固定前缀和监听端点作为名称，只操作本工具拥有的规则。
- 修改包含一个顺序步骤列表，每个步骤携带逆操作。后续步骤失败时，逆序恢复已经完成的步骤。恢复失败时同时报告原始错误和恢复错误。
- 子进程设置超时并捕获标准输出和错误，异常不能作为成功处理。
- 连通性通过 TcpClient 异步连接，设置超时；只说明目标 TCP 能否连接，不声称服务内容或外网已经可用。

## 约束与先决条件
Windows 10/11 x64；宿主机可达虚拟机；IP Helper 服务可用。不会自动配置交换机、ICS、路由器或虚拟机防火墙。UDP 不属于首版。默认不授予防火墙放行，不自动修改启动项。

中文界面和中文注释；至少每三行代码一行中文注释；函数最多 50 行；行为常量集中管理；不直接删除用户文件；无第三方运行时依赖。

## 验证
自动检查覆盖 IPv4 与端口边界、命令参数、重复和通配地址冲突、过期数据、防火墙失败恢复、编辑失败恢复及恢复错误。Windows 验证仅执行只读规则查询和真实窗口检查，不添加或删除本机规则。本地 TCP 监听器验证连接检测。最终执行 Release 构建、自包含发布和发布程序启动检查，并提供明确的未验证范围。
